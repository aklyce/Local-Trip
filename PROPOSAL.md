# 💡 Idea
Local-Trip is a platform that helps plan trips to different places. The user puts in location, dates, and other details and gets a dashboard-like overview of different factors like weather, events around the area, the distance from the start point to the destination, etc. The user then is able to review past trips and plans, as these are saved to a local database.
